# Quake3Dviewer（震源分布 3Dビューア）

日本周辺で発生した地震の震央位置・深さ・マグニチュードを、3D空間で立体的に見られるツールです。気象庁（JMA）が公開している震源データ・火山の噴火警報データをブラウザから直接取得して表示します。

## 使い方

- **ドラッグ**：地図を回転（左右にドラッグで方角、上下にドラッグで傾き）
- **スクロール／ピンチ**：拡大・縮小
- 画面右下のアイコンドックから、地震一覧・検索・表示設定・火山情報の4つの機能を切り替えられます
  - 同じアイコンをもう一度押すとパネルを閉じます。閉じてもどのタブを開いていたかは保持され、別のアイコンを押すまでは元のタブのまま（再度アイコンを押せば同じ内容にすぐ戻ります）

### アイコンドックのタブ

| タブ | 内容 |
|---|---|
| 地震一覧 | 直近の地震をリアルタイム（P2P地震情報）で受信。タップで震度分布・詳細を表示し、震源へ地図を移動 |
| 検索 | 気象庁 震度データベース（eqdb）から、期間・マグニチュード・地域などで過去の地震を検索 |
| 表示設定 | 表示期間・最小マグニチュード・深さ方向の強調・引き出し線のオン/オフ・最新データの再取得 |
| 火山情報 | 全国の火山（気象庁対象の常時観測火山など）の噴火警報・予報を地図上に三角アイコンで表示。一覧は警戒度が高い順に全件表示 |

### 見方（震源の3D表示）

| 表現 | 意味 |
|---|---|
| 点の色 | 震源の深さ（赤系＝浅い、オレンジ→黄→水色系＝深い） |
| 点の大きさ | マグニチュード（大きいほど規模が大きい） |
| 点の高さ（沈み込み） | 深さ方向の位置。「深さ方向の強調」スライダーで見やすさを調整可能 |
| 引き出し線 | 各震源から地表までの線。オンにすると深さが分かりやすくなります |

### 見方（火山情報）

| 表現 | 意味 |
|---|---|
| 三角アイコンの色 | 警戒レベル・警戒状態（気象庁の配色に準拠：紫＝最も警戒度が高い、赤、橙、黄の順に下がり、灰色＝平常・情報なし） |
| 三角アイコン内の数字 | 噴火警戒レベル（1〜5）。数字が出るのは「噴火警戒レベル」が運用されている火山のみ |
| 輪郭が実線 | 噴火警戒レベルが運用されている火山 |
| 輪郭が点線 | 噴火警戒レベルが運用されていない火山（文言で警戒状態が発表される火山）、または警戒情報の発表履歴がない火山 |
| 一覧の並び順 | 警戒度が高い火山から順にすべて表示（全火山を常時表示、絞り込みはありません） |

火山アイコンは地図上の他の表示より常に手前に出るようにしています。また、地図・一覧への反映は10分間隔で自動更新されます（「火山情報」タブが選択されている間だけ地図上に表示され、他のタブに切り替えると地図上のアイコンは消えます）。

### 操作パネル（表示設定タブ）

- **期間**：直近1日〜90日から選択（気象庁の日別データを取得します）
- **最小マグニチュード**：これより小さい地震は表示から除外
- **深さ方向の強調**：深さの見た目を誇張する倍率
- **地表への引き出し線**：オン/オフ切り替え
- **最新データを取得**：手動で再取得

### うまく表示されないとき

- 震源データの取得に失敗した場合、画面に「再試行」または「サンプルで表示」ボタンが出ます。「サンプルで表示」を選ぶと、通信状況に関わらず操作感を確認できます
- 一部の日だけ取得に失敗した場合は、画面下に警告メッセージが一時的に表示されます（他の日のデータは正常に表示されます）
- 火山情報の取得に失敗した場合は、一覧パネルにエラーメッセージと「再試行」ボタンが表示されます

## データについて

- **震源データ**：気象庁（JMA）が公開する日別の震源データ（`https://www.jma.go.jp/bosai/hypo/data/...`）を、閲覧時にブラウザから直接取得しています。一度取得した日のデータは端末内（IndexedDB）に保存され、次回以降は再取得しません
- **火山データ**：
  - 火山の位置・名称などの基本情報は、あらかじめアプリに同梱された静的データ（`volcano_list.json`）を使用しています
  - 現在の警戒レベル・警戒状態は、気象庁が公開する`warning.json`（噴火警報・予報の発表履歴）を10分間隔でブラウザから直接取得し、火山ごとに最新の状態を集計して表示しています
- **地図データ**：世界の国土・日本の都道府県境界のポリゴンデータを使用しています（座標精度を間引いて軽量化済み）
- いずれのデータも、このアプリを開いているあなたの端末とJMA/データ提供元のサーバーの間で直接やり取りされ、開発者側には送信・保存されません

## 既知の制限

- 深さの表現は見やすさのための誇張であり、実際の縮尺とは異なります
- 完全に真上から見る視点は、深い震源の表示が不安定になるため制限しています（ごくわずかに傾いた状態が最も真上に近い視点です）
- 地図の海岸線・県境は座標を簡略化しているため、詳細な測量用途には使用できません
- 火山の警戒状態コードのうち一部（噴火警戒レベル4、レベル未運用火山の「平常」、「山麓厳重警戒」）は、参照した気象庁資料内に直接の例がなく、コード体系の並びからの推定です。実際の発表内容と一致しない場合、該当の火山はグレー表示（不明）にフォールバックします

## 開発者向け情報

このリポジトリはReact + Vite + MapLibre GL JS + Three.jsで構成されており、GitHub Pagesにそのままデプロイできます。

### セットアップ

```bash
npm install
npm run dev
```

### ビルド／デプロイ

```bash
npm run build     # dist/ に静的ファイルを出力
npm run deploy    # gh-pages ブランチへ手動デプロイ
```

`.github/workflows/deploy.yml` を使えば、`main` ブランチへのpushで自動ビルド・デプロイされます（リポジトリの Settings → Pages → Source を「GitHub Actions」に設定してください）。

### ディレクトリ構成

```
src/
  App.jsx                        画面全体の状態管理
  components/                     UIコンポーネント一式
    IconDock.jsx                   右下のアイコンドック（4タブの開閉・切り替え）
    MapSettingsPanel.jsx           表示設定タブの中身
    quake/                         地震一覧・検索タブの中身
    volcano/                       火山情報タブの中身（一覧・詳細カード）
  lib/
    QuakeMapEngine.js               地図・3Dレイヤーのコアロジック（震源の点群＋火山シンボルレイヤー）
    jma.js                          JMA震源データの取得・正規化・日別キャッシュ
    quakeFeed.js / useQuakeFeed.js  P2P地震情報のリアルタイム取得・一覧管理
    eqdb.js / useEqdbSearch.js      気象庁 震度データベース(eqdb)検索
    quakeMapSync.js                 選択中の地震と地図表示（震度分布・震源マーカー）の同期
    volcanoData.js                  火山マスタ(volcano_list.json)の読み込み・キャッシュ
    volcanoAlerts.js                火山の警戒状態コード表・配色・warning.jsonの取得と集計
    volcanoIcons.js                 火山用の三角アイコン(canvas)生成
    useVolcanoFeed.js               火山情報の10分間隔ポーリング・地図マーカー同期
    idb.js                          IndexedDBラッパー
    color.js                        深さ→色、マグニチュード→サイズの変換
    sampleData.js                   オフライン用サンプルデータ
public/data/
  world.json / prefectures.json     簡略化済み地図データ
  quake_stations.json / quake_regions.json / quake_epicenter_names.json
                                     震度観測点・細分区域・震源地名のマスタ

```

### 未検証・要注意事項

- 気象庁サーバー（震源データ・`warning.json`）のCORS許可状況は未検証です。ブロックされる場合は簡易プロキシの追加が必要になる可能性があります
- 震源データの `mj`・`aflag`・`flag` プロパティの意味は未確認のためUIには使用していません
- 火山の警戒状態コードのうち `14`（噴火警戒レベル4）、`21`（レベル未運用火山の「平常」）、`24`（「山麓厳重警戒」）は、気象庁の解説資料内に直接のサンプルがなく、コード体系の並びからの推定です。実データで異なるコードが確認された場合は `src/lib/volcanoAlerts.js` の `VOLCANO_ALERT_CODES` を修正してください
